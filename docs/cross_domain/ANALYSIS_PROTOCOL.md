# Cross-domain single-mechanism protocol

Frozen before numerical comparisons in this audit, 2026-10-07. The historical targets were already known to the user/assistant; this is retrospective and cannot become a blind prospective test. This file fixes the procedure before new target retrieval and numerical synthesis.

1. Recover targets at immutable source commits. Priority for the primary frozen quantity: executable pre-holdout manifest/configuration, explicit freeze protocol, result tied to that protocol, then paper. Preserve competing pipelines and exploratory fits as separately typed records. Do not replace a failed/less-convenient target. Fe II is the explicitly requested principal NIST line species; retain Co II as a within-domain check, not a fifth independent domain.
2. Preserve source decimal strings and distinguish a fixed frequency, a fitted optimum, a scale ratio, and a calibration/scan range. P-values, grid steps and cross-bin variability are not frequency uncertainties. Use reported statistical intervals only for their declared estimand.
3. Typed re-expression rules are fixed algebra: ell=log(x/x_ref); x->c x changes phase, not log frequency; y=c x^p gives nu_y=nu_x/p and lambda_y=lambda_x^p; reciprocal coordinates reverse phase orientation. For a documented DSI scale ratio lambda, nu=2pi/log(lambda). A mass/root-mass transformation is permitted only when the source observable actually uses it. Dividing a dimensionless scale ratio by two is not the coordinate rule for squared mass.
4. U0 tests equality of native, dimensionless log-frequency magnitudes, only for targets with an identified log-periodic estimand. U1 applies only source-required coordinate maps to a declared common mass/energy coordinate; it is an equality hypothesis, not already a WCT prediction. If a domain lacks the needed estimand or map, report the four-domain model as ineligible rather than inventing a target.
5. U2 uses nu_i=2pi n_i/Delta_ell only with independently supplied integer assignments and common/domain-derived widths. No target-fitted integer assignment is admissible evidence. U3 requires shared S004 coefficients plus independently measured backgrounds/length maps. U4 requires the entire physical chain. Unidentified inputs yield unavailable predictions, not zero residuals.
6. For eligible U0/U1 descriptive fits without a common justified uncertainty model, minimize unweighted squared log-ratio residuals. The shared scale is the geometric mean. Leave one domain out, estimate from the other three, freeze, predict the fourth, and reverse the declared map to its original target units. Report absolute/fractional errors; normalized residuals only with legitimate target uncertainty. Refit neither the transformation nor the estimand after prediction. Alternate pre-existing pipelines get clearly separate sensitivity panels.
7. Primary admissible integer search range is empty unless an independent physical source supplies assignments. Trials from such an unperformed search are zero. To quantify manufacture-of-agreement freedom, a separate **negative-control** procedure may search integer labels 1..12, with sensitivity ranges 1..6 and 1..24. These are analyst-chosen diagnostic caps, not physical winding priors or proposed assignments. Its optimized integers cannot support a mechanism or be used as independent held-out labels.
8. The same negative-control diagnostic may compare exponent menus {1}, {1/2,1,2}, and {1/2,1,2,-1}, using magnitudes after reciprocal orientation is recorded. Menus beyond source-required maps are prohibited for confirmation and count toward transformation trials. Dataset-specific arbitrary continuous multipliers saturate four values and are reported as an unidentifiable control, not fitted as a mechanism.
9. Monte Carlo coincidence diagnostics use seed 20261007, 10000 four-tuples of independent log-uniform positive dimensionless frequencies on [1,100], with [5,50] as a declared support sensitivity. Use the identical selection/search procedure on observed and null tuples. These arbitrary support distributions measure this diagnostic procedure's flexibility; they are not calibrated physical nulls for the four experiments and cannot yield a scientific discovery p-value. If no four comparable targets exist, report the joint null as ineligible rather than filling missing values.
10. Preserve all empirical choices and source repositories. Do not read the ATLAS event holdout or rerun any empirical peak search. Work only on derived summaries and original methodological sources. Record every blocked physical dependency and every failed held-out domain.

The acceptable verdict is chosen from the user's five categories only after target/provenance and identifiability checks. A failure of equality does not by itself imply that multiple underlying mechanisms are required.
