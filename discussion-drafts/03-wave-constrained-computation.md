# Discrete Wave-Constrained Computation and Classical Complexity

**Author:** Richard J. Reyes  
**Published:** November 26, 2025  
**DOI:** https://doi.org/10.5281/zenodo.17732642  
**Category:** Computation and Cryptography

## Main result

I show that a discrete wave-constrained computer remains Turing-equivalent for classical P and NP when precision, energy, state preparation, input, and output are physically bounded.

Wave dynamics alone do not create unlimited computational power. Once the usable states and measurements are discretized, the machine can still be simulated within an ordinary classical computational model.

Any genuine advantage must therefore come from a defined physical resource, architecture, approximation guarantee, or restricted problem family rather than from hidden infinite precision.

## What this adds to the corpus

This paper separates the physical advantages of wave computation from claims that analog, resonant, or nonlinear behavior automatically escapes classical complexity. It provides the classical baseline needed before defining the more restricted WCC complexity classes.

## Direct tests

- Audit the encoding and decoding overhead for representative wave algorithms.
- Include precision and state-preparation cost explicitly in the resource measure.
- Identify which wave operations can be simulated with polynomial overhead.
- Compare the model with analog computation, real-number computation, optical computing, and quantum complexity.
