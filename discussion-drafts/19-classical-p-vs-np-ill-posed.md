# P versus NP Is Mathematically Defined but Physically Incomplete

**Author:** Richard J. Reyes  
**Published:** December 1, 2025  
**DOI:** https://doi.org/10.5281/zenodo.17783074  
**Category:** Computation and Cryptography

## Main result

I argue that the classical P versus NP framework leaves out physical resources required by every realizable computation.

Turing-machine complexity counts abstract steps. Physical computation also requires precision, energy, bandwidth, memory, state preparation, error correction, measurement, and verification.

Different physical architectures can collapse into the same abstract step-count model while having radically different real resource costs. A complete physical complexity theory must therefore include those resources rather than treating them as external implementation details.

## What this adds to the corpus

This paper explains why the WCC framework introduces curvature, propagation, precision, preparation, and measurement as first-class computational resources. It gives the conceptual basis for both the Turing-equivalence paper and the model-relative Pᵂᶜᶜ ≠ NPᵂᶜᶜ result.

## Direct tests

- Formalize a resource vector that includes time, energy, precision, space, and preparation.
- Compare machines with the same step complexity but different physical costs.
- Determine which resource-aware complexity frameworks already capture each concern.
- Separate claims about formal mathematics from claims about realizable computation.
- Test whether the proposed additions change classification for concrete problem families.
