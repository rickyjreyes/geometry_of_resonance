# Bin-Stable Log-Periodic Structure in the Public NIST Atomic Line Data

**Author:** Richard J. Reyes  
**Published:** May 28, 2026  
**DOI:** https://doi.org/10.5281/zenodo.20435463  
**Category:** Open-Data Tests / Atomic Spectra

## Main result

I analyzed the public NIST Atomic Line List in logarithmic spectral coordinates and found recurring structure that remains stable under changes in bin width, bin origin, filtering, and data subsets.

That stability is important because a histogram artifact should normally move, weaken, or disappear when the binning procedure changes. The observed persistence indicates that the structure is tied to the underlying catalog rather than one selected visualization.

The result is consistent with discrete-scale organization of atomic spectra and with the type of log-periodic structure predicted by Wave Confinement Theory.

## What this adds to the corpus

This is a public-data test of a recurring WCT prediction: organized physical spectra may contain approximately periodic structure in logarithmic coordinates. The analysis moves that claim away from selected individual constants and into a large external atomic database.

## Direct tests

- Build surrogate catalogs that preserve the observed selection function and line density.
- Separate element families, ionization states, and correlated transition series.
- Apply global significance and look-elsewhere corrections.
- Repeat the fixed pipeline on independent atomic and molecular databases.
- Measure whether the same log period persists across physically distinct subsets.
