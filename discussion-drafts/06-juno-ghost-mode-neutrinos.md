# JUNO Detectability of an Additional WCT Neutrino Ghost Mode

**Author:** Richard J. Reyes  
**Published:** November 20, 2025  
**DOI:** https://doi.org/10.5281/zenodo.17715872  
**Category:** Open-Data Tests / Neutrino Physics

## Main result

I modeled whether JUNO could resolve a weak additional oscillatory neutrino mode predicted by a WCT-based extension.

The paper includes detector energy resolution, reactor-baseline smearing, standard three-flavor oscillations, nonlinear energy response, and interference with the ordinary spectrum.

The result defines the amplitude and frequency range in which the additional mode should remain visible after convolution with the JUNO response.

## What this adds to the corpus

This paper converts the WCT ghost-mode idea into an experiment-specific detectability question. It defines where the effect would survive realistic resolution and where it would become degenerate with ordinary oscillation structure.

## Direct tests

- Run a full binned likelihood with JUNO nuisance parameters.
- Compare the mode against mass-ordering structure and energy-scale nonlinearities.
- Include the reactor-core baseline distribution and background spectra.
- Test Fourier, wavelet, and direct spectral fits with the same injected signal.
- Publish fixed detection thresholds before examining final data.
