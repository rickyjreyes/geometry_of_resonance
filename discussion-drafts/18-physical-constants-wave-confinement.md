# Physical Constants from Wave-Confinement Geometry

**Author:** Richard J. Reyes  
**Published:** April 26, 2025  
**DOI:** https://doi.org/10.5281/zenodo.15596159  
**Category:** Mass and Geometry

## Main result

I developed a framework in which physical constants and mass ratios emerge from harmonic indices, curvature scales, winding numbers, and confinement geometry.

The paper identifies structured relationships across several measured quantities rather than treating each value as independent. The central claim is that at least part of the apparent parameter set may reflect a smaller geometric and harmonic structure.

## What this adds to the corpus

This paper is the constants branch of WCT. It connects the core curvature and confinement framework to numerical physical quantities and defines a program for testing whether the same rules generate multiple constants consistently.

## Direct tests

- Count every adjustable scale, integer choice, and assignment rule.
- Freeze the mapping rules before testing additional quantities.
- Report failed assignments and alternative matches.
- Measure sensitivity to updated experimental values.
- Compare predictive error against simple null models with the same freedom.
- Require out-of-sample predictions that were not used to construct the mapping.
