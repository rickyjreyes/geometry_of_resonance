# WaveLock: A One-Way Function Based on Nonlinear PDE Evolution

**Author:** Richard J. Reyes  
**Published:** December 1, 2025  
**DOI:** https://doi.org/10.5281/zenodo.19122146  
**Category:** Computation and Cryptography

## Main result

I designed a proposed one-way function based on nonlinear curvature-locked PDE evolution.

The forward map evolves an encoded input through a nonlinear field equation and extracts a final observable or state representation. The intended asymmetry comes from nonlinear mixing, constrained observability, sensitivity, and controlled information loss.

WaveLock turns the WCT computational substrate into a concrete cryptographic construction with an explicit forward process and a defined inversion problem.

## What this adds to the corpus

This paper connects curvature-bounded wave computation to practical security. It asks whether the same nonlinear field evolution used for confinement can create useful computational asymmetry.

## Direct tests

- Define the security parameter, input distribution, output map, and collision criterion.
- Test gradient inversion, adjoint methods, differentiable solvers, and surrogate models.
- Measure collision resistance and output bias across discretizations.
- Run chosen-input, related-input, and partial-observation attacks.
- Separate information loss from numerical instability.
- Compare cost and security with established hash, lattice, and memory-hard constructions.
