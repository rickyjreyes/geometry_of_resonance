# Ordered Fourier Eigenmodes Emerging from Chaos

**Author:** Richard J. Reyes  
**Published:** September 16, 2025  
**DOI:** https://doi.org/10.5281/zenodo.17732648  
**Category:** Core WCT / Pattern Formation

## Main result

I showed how nonlinear finite-band dynamics can drive random initial conditions into a small set of organized Fourier modes.

The system begins in a disordered state and develops stable cymatic-like patterns through mode competition, shell selection, and spectral concentration. The spectral entropy decreases as the field moves toward finite Fourier support.

The result provides a concrete mechanism for order emerging from noisy continuous dynamics without imposing the final pattern.

## What this adds to the corpus

This paper supplies the numerical and dynamical bridge between the PFF finite-k instability and the stable shell structures used throughout WCT. It makes the emergence claim visible and measurable in Fourier space.

## Direct tests

- Reproduce the result across grid sizes, timesteps, and boundary conditions.
- Compare measured k⋆ with the analytic finite-band prediction.
- Track entropy, shell width, defect density, and convergence time.
- Test sensitivity to initial spectra and noise amplitude.
- Compare directly with Swift–Hohenberg, Turing-pattern, and mode-locking systems.
